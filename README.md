# Conferência de Estoque — Esquina da Carne

Aplicativo HTML independente para conferir o inventário exportado do TIAPPS.

## Publicação HTTPS (GitHub Pages)

1. Coloque o arquivo funcional do aplicativo como `index.html` na raiz deste repositório.
2. Em **Settings → Pages**, selecione **GitHub Actions** como origem da publicação.
3. A cada atualização na branch `main`, o workflow publica o site automaticamente.

O endereço esperado será: https://martinsewerton100-code.github.io/estoque-esquina-carne/

## Importante

- Este projeto é independente do Gestor Pampa e do TIAPPS.
- Os dados editados no navegador ficam armazenados localmente; exporte backups.
- A câmera ao vivo exige HTTPS e autorização do navegador.
